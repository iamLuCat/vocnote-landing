# VocNote — Landing Page

Marketing landing page for **VocNote**, a kawaii-academic English vocabulary
notebook app for iPhone, iPad and Mac.

- **App Store:** https://apps.apple.com/us/app/vocnote/id6807695153
- **Facebook:** https://www.facebook.com/people/VocNote/61593695176302/

Static, single-file site (`index.html` + mascot images). Bilingual Vietnamese /
English with an in-page toggle. Design follows VocNote's "Pastel Scholar" system
(Quicksand type, cream/coral palette, sage-green success accent, the clay-3D
squirrel mascot **Sóc**).

## Run locally

Just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Served as-is via GitHub Pages (Settings → Pages → Branch `main` / root), or any
static host (Cloudflare Pages, Netlify, Vercel).

No build step, no dependencies. Fonts load from Google Fonts.
